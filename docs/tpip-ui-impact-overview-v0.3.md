# TPIP 治理工作台影响总览 v0.3

## 已完成

- 任务详情新增全量风险分布条带和四级风险图例；
- 展示变化报告、新增超期、新增提醒候选三个影响指标；
- 展示任务全量成功、失败、执行中、待执行状态；
- 摘要独立处理加载、失败和重试，不阻断任务基础事实；
- 顶部新增 Control Plane 在线状态，每 15 秒读取 `/actuator/health`；
- 健康状态支持 CHECKING、ONLINE、OFFLINE，点击可立即重试；
- “刷新详情”现在同时刷新详情、摘要、Workspace 明细和时间线；
- 未引入 ECharts，当前关系使用轻量 CSS 分布条即可清晰表达。

## 数据真实性

风险和影响指标来自 v1.5 服务端全量聚合接口，不使用当前 Workspace 分页做推断。UI 明确标注“非当前分页统计”。

## 质量结果

- 前端 6 个测试文件、10 个测试通过；
- Vue/TypeScript 严格检查与 production build 通过；
- 最大 JS chunk 约 380 KB，未破坏 v0.2 体积门禁；
- 健康和摘要均通过 Vite `18100 → 18082` 真实代理链路验证。

## 仍保持的边界

- 无登录、OIDC/JWT、RBAC；
- UI 只读，治理操作按钮不执行命令；
- 仅监听 loopback；
- 不在浏览器保存数据库密码、Token 或第三方 Secret；
- 本阶段未运行 Playwright 真实浏览器。

## 下一步

进入 UI v0.4 受控写操作准备：先统一命令 API Client、并发版本和错误模型，再实现确认对话框；不直接把按钮绑定到 HTTP 请求。
